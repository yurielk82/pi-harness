# Learn

Review the harness memory files and improve them so future sessions get better.

## Tasks

1. Read `.pi/memory/project.md`, `.pi/memory/work-style.md`, `.pi/memory/learnings.md`, and `.pi/workflows/*.md`.
2. Summarize the current durable memory.
3. Identify stale, duplicated, or contradictory entries.
4. If clear improvements are warranted, update the memory files directly.
5. Propose any missing durable memory that should be captured next.

## Important Constraint

- Do not invent company facts when the docs or memory files are empty.
- Preserve `TBD` where the real answer is unknown.
- Prefer explicit gaps over plausible-sounding fiction.

## Output

Respond with:
- a short memory summary
- stale or risky entries
- proposed additions
