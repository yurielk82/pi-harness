# Review Readiness

Assess whether the current task has enough definition, testing, and review coverage.

## Tasks

1. Read:
   - `.pi/workflows/problem.md`
   - `.pi/workflows/plan.md`
   - `.pi/workflows/test-plan.md`
   - `.pi/workflows/review-readiness.md`
   - `.pi/workflows/release.md`
2. Inspect the current git diff if relevant.
3. Determine readiness across:
   - problem framing
   - plan quality
   - test coverage plan
   - docs impact
   - security or hardening review
   - release readiness
4. Update `.pi/workflows/review-readiness.md`.
5. Recommend the next team, chain, or command.

## Output

Respond with:
- a pass/fail checklist
- the blocking gaps
- the next recommended action
