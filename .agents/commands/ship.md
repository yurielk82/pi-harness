# Ship

Prepare the current work for release like a pragmatic release manager.

## Tasks

1. Read:
   - `.pi/workflows/problem.md`
   - `.pi/workflows/plan.md`
   - `.pi/workflows/test-plan.md`
   - `.pi/workflows/review-readiness.md`
   - `.pi/workflows/release.md`
2. Inspect the current diff and recent test evidence.
3. Summarize:
   - what changed
   - who is affected
   - rollout guidance
   - rollback plan
   - unresolved risks
4. Update `.pi/workflows/release.md`.
5. State whether the change is ready to ship and what still blocks it.

## Output

Respond with:
- ship recommendation
- key release notes
- rollout and rollback notes
