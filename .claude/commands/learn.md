# Learn

Review the harness memory files and improve them so future sessions get better.

## Tasks

1. Read `.pi/memory/project.md`, `.pi/memory/work-style.md`, `.pi/memory/learnings.md`, and `.pi/workflows/*.md`.
2. Summarize the current durable memory.

4. If clear improvements are warranted, update the memory files directly.

## Output

- proposed additions
