# Release Checklist

Use this file to define the minimum conditions for shipping work safely.

## Core Checks

- Problem framed
- Plan reviewed
- Tests run
- Results validated
- Docs updated
- Release notes written
- Rollback path understood
- Monitoring or verification defined

## Additional Checks For Risky Changes

- Security review
- Data contract review
- Migration plan
- Backfill plan
- Permission / secret review

## Notes

- Keep this aligned with `.pi/workflows/review-readiness.md` and `.pi/workflows/release.md`.
- Use this as a minimum bar, not a place to invent process for its own sake.
