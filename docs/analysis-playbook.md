# Analysis Playbook

Use this file for recurring expectations around exploratory analysis and decision support.

## Standard Structure

1. Business question
2. Metric definition
3. Data source and grain
4. Assumptions
5. Method
6. Findings
7. Caveats
8. Recommendation

## Common Failure Modes

- Ambiguous metric definitions
- Hidden filters
- Broken joins
- Survivorship bias
- Leakage from future information
- Over-reading noisy segments

## Notes

- Keep analytical work tied to a concrete decision whenever possible.
- If the business question is weak, rewrite it before doing deeper analysis.
