# Workflow Artifacts

These files are the shared handoff layer between planning, implementation,
review, and reflection.

- `problem.md`: business framing, scope, metrics, constraints, and unknowns
- `plan.md`: implementation plan, owners, risks, and rollout shape
- `test-plan.md`: validation approach, checks, and evidence to gather
- `review-readiness.md`: what reviews and artifacts are still missing before ship
- `release.md`: release notes, rollout notes, and deploy checkpoints
- `retro.md`: what changed, what failed, and what should improve next time

Treat these as living working files. Update them when a task changes direction.
